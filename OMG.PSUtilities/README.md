# OMG.PSUtilities

`OMG.PSUtilities` is the meta-module for the complete module portfolio.

## Installation

```powershell
Install-Module -Name OMG.PSUtilities -Scope CurrentUser -Repository PSGallery
```

Installing this package installs all supported `OMG.PSUtilities.*` modules.
Install an individual module when only one domain is required.

```powershell
Install-Module -Name OMG.PSUtilities.AzureDevOps -Scope CurrentUser -Repository PSGallery
```
