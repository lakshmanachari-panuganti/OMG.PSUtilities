The deferral below is retained as the historical record of why Phase 8 was blocked. The owner
selected MIT on 2026-08-17. Read `0.5-licensing-selection.md` for the binding license, holder,
year range, and Phase 8 file inventory.

## Decision

Do not add a license file or change copyright and `LicenseUri` metadata until the copyright
owner explicitly selects a license. The repository's present default rights state remains
unchanged during this deferral; that is not a final choice of a proprietary license.

Phase 8 licensing work is blocked. No contributor or automation may infer legal intent from
the changelog, commented metadata, package links, or the public visibility of the repository.

## Evidence

The repository currently contains contradictory signals:

- No `LICENSE` or `LICENSE.*` file exists in tracked source.
- All seven functional module manifests state `All rights reserved`.
- `OMG.DevTools.psd1` also states `All rights reserved`.
- The meta-module and DevTools manifests link to a nonexistent root `LICENSE` file.
- The AzureDevOps manifest contains a commented MIT `LicenseUri` example.
- The root changelog claims an MIT license file was added, but that file is absent.

None of these signals is sufficient to grant users legal rights.

## Required Owner Choice

The copyright owner must approve one of these outcomes in writing:

1. **MIT:** add the canonical MIT license text and align every active package manifest.
2. **Apache-2.0:** add the canonical Apache-2.0 license and required notices, then align
   manifests.
3. **Proprietary / all rights reserved:** retain the restricted rights state and remove every
   public metadata claim that a permissive license exists.
4. **Another license:** provide the exact SPDX identifier and approved license text.

The owner must also confirm the copyright holder name and applicable year range.

## Unblocking G6

G6 becomes satisfied only when a follow-up decision record:

- names the selected license and SPDX identifier;
- records explicit owner approval;
- identifies the approved copyright holder and year range; and
- defines the manifest, changelog, package, and repository files to align in Phase 8.

Until then, release documentation must describe licensing as unresolved and must not link to
a nonexistent license file.
