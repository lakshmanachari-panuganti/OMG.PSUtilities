## Owner Approval

The owner supplied all three facts required by `0.3-licensing.md` in a single written
confirmation on 2026-08-17, in response to a direct request that presented MIT, Apache-2.0,
proprietary/all-rights-reserved, and other-SPDX as equally available outcomes. No fact in
this record is inferred from repository visibility, comments, changelog text, package links,
or existing `All rights reserved` strings.

This record grants no rights on its own. Rights are granted only by the `LICENSE` file added
in Phase 8.

## Canonical Values For Phase 8

Phase 8 must apply exactly these strings. Do not paraphrase them per module.

- License file copyright line: `Copyright (c) 2025-2026 Lakshmanachari Panuganti`
- Manifest `Copyright`: `'(c) 2025-2026 Lakshmanachari Panuganti'`
- Manifest `LicenseUri`:
  `'https://github.com/lakshmanachari-panuganti/OMG.PSUtilities/blob/main/LICENSE'`

`All rights reserved` must be removed wherever it appears in manifest copyright strings. That
phrase asserts a reservation the MIT grant does not make, so retaining it alongside MIT would
reintroduce the contradiction this decision closes.

Both existing active `LicenseUri` values already point at the canonical URL above. They are
currently broken links; adding the root `LICENSE` file makes them resolve. Do not change them
to `https://opensource.org/licenses/MIT`, and do not leave two different URL forms in the
repository.
